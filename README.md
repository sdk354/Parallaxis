# Parallaxis

## Concept
Parallaxis is an open, accessible geopolitical intelligence and media analysis platform that gives journalists, researchers, students, and engaged citizens the analytical tools previously only available to governments and enterprise intelligence firms.

The name comes from the physics concept of **parallax** — the apparent shift in an object's position depending on the angle you view it from. This describes the platform's core insight: the same geopolitical event looks completely different depending on where you're standing.

## Core Pitch
> "An open intelligence platform that gives citizens the analytical tools previously only available to governments and enterprise intelligence firms — transparent about methodology, honest about uncertainty, and designed to develop critical thinking rather than replace it."

## Platform Type
- **Web application** (responsive, works on mobile)
- Map-first design: the interactive globe is the home screen and central hub
- Every feature flows from the map — click a conflict, access all analytical tools for that event

## Key Differentiator
Unlike WorldMonitor (worldmonitor.app) which tracks *what is happening* (military assets, conflict events), Parallaxis analyses *how events are being framed, manipulated, and narrativised* across different geopolitical perspectives.

Unlike Ground News, AllSides, and similar tools which offer per-article bias ratings, Parallaxis provides deep analytical tools, multi-perspective narrative comparison, and a geographically-organised intelligence layer.

## Design Principles
1. Every conclusion is traceable to a primary source — no black-box verdicts
2. Honest about uncertainty — confidence scores, not binary labels
3. Designed to develop critical thinking, not replace it
4. Transparent methodology throughout
5. Open and accessible — not paywalled enterprise intelligence

## Target Users
- Journalists and fact-checkers
- Researchers and academics
- Students (politics, IR, journalism, media studies)
- Policy-interested general public
